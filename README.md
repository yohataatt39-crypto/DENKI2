# 施工経験記述トレーニング

1級電気工事施工管理技士 二次試験の「施工経験記述」専用Webアプリです。

## Version
1.0

## 収録条件
- 工程管理：夜間・終業時間外、土日祝のみ、関連工事との時間競合、関連工事の遅れ、設計変更
- 安全管理（墜落・飛来落下）：高所作業車、足場・ローリングタワー・梯子・脚立
- 品質管理：施工条件が良くない場所、関連工事と輻輳する場所
- 安全管理（感電）：水気・湿気の多い現場

ユーザーが既に作成した施工経験記述は「自分の記述例」として収録しています。

## 機能
- 与条件のカテゴリ選択
- 問題点・対策の記述練習
- 入力途中の文章をブラウザの LocalStorage に自動保存
- 記述後に着眼点を表示
- 作成済みの自分の記述例を参照
- スマートフォン向けレスポンシブ表示

## GitHub Pages
`index.html`、`style.css`、`app.js`、`README.md` を新しいリポジトリのルートへ配置してください。

GitHub の `Settings` → `Pages` → `Deploy from a branch` を選択し、`main` / `/(root)` を指定します。

このアプリは以前作成した技術記述アプリとは独立しています。既存アプリのファイルを上書きせず、別リポジトリまたは別ディレクトリで公開してください。
